# Pi Motion Cam (Raspberry Pi 5 + Camera Module)

Watches a low-res camera stream, detects motion (OpenCV frame differencing), checks for people
(OpenCV HOG), optionally recognizes faces, boxes them, saves a full-res JPEG to `captures/`, and
sends it to Telegram.

**Try it in your browser:** https://vibhvesh.github.io/pi-motion-cam/ (webcam demo, all processing local)

## 1. Camera
Bookworm auto-detects official cameras. Connect the ribbon cable with the Pi off, boot, then test:
`rpicam-hello -t 2000`. If not detected, add `camera_auto_detect=1` (or e.g. `dtoverlay=imx708`)
to `/boot/firmware/config.txt` and reboot.

## 2. Install
One-line installer (clones to `~/pi-motion-cam` and runs `install.sh`):
```bash
curl -sSL https://raw.githubusercontent.com/vibhvesh/pi-motion-cam/main/get.sh | bash
# with face recognition:
curl -sSL https://raw.githubusercontent.com/vibhvesh/pi-motion-cam/main/get.sh | bash -s -- --face
```
Or manually:
```bash
cd ~/pi-motion-cam
./install.sh          # or ./install.sh --face  for face recognition (slow dlib build)
```
The venv uses `--system-site-packages` so apt's picamera2/OpenCV are visible.

## 3. Telegram bot
1. In Telegram, message **@BotFather** → `/newbot` → copy the token.
2. Send any message to your new bot.
3. Open `https://api.telegram.org/bot<TOKEN>/getUpdates` and copy `"chat":{"id": ...}`.
4. Put both in `config.yaml` or env vars `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` (env wins).

## 4. Face recognition (optional)
Put one clear photo per person in `known_faces/` named by person: `alice.jpg`, `bob.png`
Multiple photos per person are supported and improve accuracy: `alice_1.jpg`, `alice_2.jpg`, `alice_3.jpg` all count as alice (each photo adds a face encoding; matching uses the closest one). Use 3–5 clear photos with different angles/lighting. Set `face_recognition.enabled: true`. Unmatched faces → `Unknown`.

**Labeling unknown people:** each new unrecognized face is cropped and saved to `unknown_faces/unknown_YYYYMMDD_HHMMSS_N.jpg`
(the same stranger isn't saved again while the program runs), and the Telegram caption says *"Unknown person — please label in admin panel"*.
To label one, rename the file to the person's name and move it into `known_faces/`, e.g.
`mv unknown_faces/unknown_20261103_191502_1.jpg known_faces/alice_3.jpg`.
`known_faces/` is re-scanned automatically on the next motion event — no restart needed.

## 5. Attendance (optional)
Set `attendance.enabled: true` (requires face recognition). Each recognized person is written to
`attendance/YYYY-MM-DD.csv` with columns `name, first_seen_in, last_seen_out, photo`. Seeing the same
person again within `relog_gap_minutes` updates their OUT time; after the gap a new IN row starts.

## 6. In/Out direction counting (optional)
Set `direction.enabled: true`. The largest moving blob's centroid on the low-res stream is tracked
every frame; crossing the virtual line (`orientation`, `position`) counts IN if it matches
`in_direction`, else OUT. Events go to `events.csv` (timestamp, direction, movement, totals), the
line and counts are drawn on photos, and the latest direction is included in Telegram captions.
Simple single-blob tracking: works best with one person crossing at a time.

## 7. Run
`./venv/bin/python main.py`  — tune `motion.pixel_threshold`, `min_area`, `cooldown_seconds` in config.yaml.
Set `person_detection.require_person: false` to alert on any motion.

## 8. systemd service
```bash
sudo cp pi-motion-cam.local.service /etc/systemd/system/pi-motion-cam.service   # generated by install.sh; add Telegram env if needed
sudo systemctl daemon-reload
sudo systemctl enable --now pi-motion-cam
journalctl -u pi-motion-cam -f
```

## Autostart service
`install.sh` generates `pi-motion-cam.local.service` with your user and path filled in; it prints the commands to enable it.
